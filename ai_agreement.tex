\subsection*{Department-wide policies.} 
These apply to every thesis and cannot be modified by this agreement: (1) AI tools may not be used to generate any prose that appears in the thesis text; all writing must be the student’s own. (2) The thesis must reflect the student’s own understanding of its material, and the student is responsible for its entire content at orals.

\subsection*{Project-specific agreements}
No AI will be used for any of:
\begin{itemize}
  \item Code and Computation 
  \item Literature search and reading
  \item Mathematical content
  \item Learning aids
  \item Writing-adjacent tools
  \item Default AI features
\end{itemize}

\subsection*{Disclosure} How and when AI use will be documented during the year, and how it will be disclosed in the final document (e.g., acknowledgments, footnotes, appendix). \\
\label{sbsec: disclosure}

There are no plans to use any AI. If AI is used it will be cited in a footnote if used to assist with understanding a topic or scan literature, a formal citation if used to aid with mathematical content or for creating some work (consistent with earlier policies), or an acknowledgement otherwise.

\subsection*{Revisions} How tools not discussed above will be handled when they come up, and when this agreement will be revisited. \\

AI-based tools will not be used under any circumstances. If either the student or the advisor suspects a tool may be using AI features, they will discuss the concern in a meeting and discuss methods for disclosing the use consistent with the policies in the \hyperref[sbsec: disclosure]{disclosure agreement}. \\
